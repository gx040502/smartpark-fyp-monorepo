## Folder Structure

### Main System Modules

| Folder | Description |
|---|---|
| **CAR MODEL** | Models, scripts, and weights dedicated to detecting vehicles from video or image inputs. |
| **CAR_CLASSIFICATION** | Vehicle attribute classification models (car make and model categories). |
| **LICENSE PLATE** | Pipeline and data focused on localizing, cropping, and extracting license plates from vehicles. |
| **OCR** | Optical character recognition models and logic used to read text characters from cropped license plates. |
| **test_outputs.zip** | Compressed archive containing packaged evaluation logs, inference results, and visualization outputs from testing phases. |

### Working Data & Pipeline Directories

| Folder | Description |
|---|---|
| **datasets** | Primary training and validation data splits (images and annotation labels). |
| **datasets_test** | Independent test data splits used to evaluate final model performance. |
| **outputs** | Training run outputs, saved model checkpoints, and generated logs. |
| **predicts** | Raw inference predictions generated by the models on new image inputs. |
| **test_outputs** | Working folder for test evaluations, containing output files, metrics, and comparison visualizations. |
